# Drawable Assets — Optional Premium Visual Pack

The app already works without these assets. If you want the visual polish to match the 16-screen reference more closely, add these PNG/WebP/SVG files under `app/src/main/res/drawable/`.

## Required / high-value
1. `acrenex_logo.png` — transparent AcreNex logo, 512x512.
2. `hero_landscape.webp` — subtle GIS/cadastral aerial background, 1600x900.
3. `parcel_grid.webp` — clean cadastral parcel pattern, 1200x800.
4. `india_land_stack_outline.webp` — India silhouette with subtle parcel-grid texture, 1200x900.
5. `gis_parcel_cluster.webp` — stylized parcel-boundary illustration, 1200x700.
6. `ai_land_assistant.webp` — government-grade AI + GIS illustration, 1200x700.
7. `document_ocr.webp` — land document scan + OCR illustration, 1200x700.
8. `change_detection.webp` — before/after GIS or satellite change-detection illustration, 1200x700.

## Style direction
- Transparent backgrounds for icons.
- Avoid copyrighted government seals unless you have permission.
- Use the AcreNex navy/blue/green palette: `#123B5D`, `#1261A0`, `#16806A`, `#F4F7FA`.
- Keep imagery factual and non-political.
