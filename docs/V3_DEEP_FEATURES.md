# V3 Deep Features

This build adds three explanation-first screens without changing the existing citizen/officer architecture:

- **Parcel 360**: shows every major Land Stack layer linked to one ULPIN.
- **AI Governance Review**: exposes score, evidence, reasons and human-review action instead of presenting AI as an autonomous authority.
- **Inter-Department Workflow**: visualises how a citizen request can move across Revenue, Registration, Planning, Fiscal, Restrictions, AI review and final officer decision.

These screens are intended to make the prototype easier to explain during evaluation and to demonstrate that the solution is a workflow/integration platform, not only a collection of UI pages.
