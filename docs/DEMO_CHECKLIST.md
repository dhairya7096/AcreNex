# AcreNex Demo Checklist

1. Launch -> Splash -> Login.
2. Tap DigiLocker-assisted login -> DigiLocker Authentication -> Proof Verification.
3. Enter any demo proof string with 4+ characters.
4. Continue -> Citizen Dashboard.
5. Open primary parcel -> Parcel Intelligence.
6. Demonstrate Ownership, RoR, Building Permission, Tax/Valuation, Restrictions, Utilities, Dispute and AI Change Detection.
7. From dashboard open Land Stack Intelligence to show the complete layer ecosystem.
8. Open AI Land Assistant and demonstrate:
   - parcel-grounded question answering
   - risk scan
   - document OCR
   - document-to-parcel consistency
   - GIS change detection
9. Open Data Quality and Interoperability to demonstrate governance controls.
10. Open Officer Dashboard -> Predictive Governance / Alerts / Audit Trail.

## What to say during judging
- “ULPIN is the common parcel key.”
- “AcreNex does not replace state systems; it provides a configurable interoperability layer around the parcel.”
- “The demo data is synthetic. Department-approved APIs can replace the adapters.”
- “AI is decision support, not an autonomous legal decision-maker.”
- “State-specific language, units and workflows are configuration-driven.”
