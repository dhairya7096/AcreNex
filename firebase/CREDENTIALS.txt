ACRENEX FIREBASE CREDENTIALS

No real Firebase credential is included in this package because Firebase project credentials must belong to the project owner's Google/Firebase account.

To connect this exact app:
1. Register Android package: com.acrenex.app
2. Fill the root firebase.properties from firebase.properties.template.
3. Enable Firebase Authentication (Email/Password), Firestore and Storage.
4. Deploy firebase/firestore.rules and firebase/storage.rules.

NEVER put a Firebase service-account private key in the Android project.
